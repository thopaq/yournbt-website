# Your Next Big Thing

Lightweight static podcast website for Gen X.

## Hosting

No build command or dependencies. Netlify publishes the repository root using netlify.toml.

## Content

Edit index.html for page copy, style.css for presentation, and app.js for episode details and topic filters. Audio and video players load only when visitors open an episode. Original logo and hosts photograph are in assets/.

## Before launch

Newsletter signup currently links to the existing Squarespace form. Connect your email provider before retiring that site. Host biography and resource links also currently point to the existing site. Contact opens an email to Admin@YourNBT.com.
